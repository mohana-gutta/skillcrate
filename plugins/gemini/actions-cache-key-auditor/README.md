# actions-cache-key-auditor (gemini)

Statically audits GitHub Actions workflows for actions/cache keys that never refresh or never hit, with cited evidence and minimal line-level patch suggestions.

## Install

From a clone of the repo: `gemini extensions link plugins/gemini/actions-cache-key-auditor`.
(`gemini extensions install <path>` also works but asks you to trust the folder interactively.)
