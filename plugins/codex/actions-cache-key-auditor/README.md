# actions-cache-key-auditor (codex)

Statically audits GitHub Actions workflows for actions/cache keys that never refresh or never hit, with cited evidence and minimal line-level patch suggestions.

## Install

Copy `.agents/skills/actions-cache-key-auditor` into your repo's `.agents/skills/` or into `~/.agents/skills/`.
Codex only discovers skills there, not from this package folder unless you start Codex inside it.
