# iam-policy-diff-reviewer (gemini)

Offline, credential-free review of AWS IAM policy changes, from two policy JSONs or directly from a terraform plan, reporting newly granted access for human review.

## Install

From a clone of the repo: `gemini extensions link plugins/gemini/iam-policy-diff-reviewer`.
(`gemini extensions install <path>` also works but asks you to trust the folder interactively.)
